# ELK 布局

正常运行 `启动.bat` 即使用 ELK 0.12.0 排版，无需试用开关。界面与命令行导出也使用该引擎。首次安装依赖运行 `npm install`。

ELK 是唯一的自动布局引擎，负责目录、文件、函数的层级摆放与正交布线。旧布局算法、交叉优化器、固定模式和试用启动入口已移除。启动、书签跳转、调整深度、切换工程和导出均使用 ELK，不再接受旧固定坐标和手工折线覆盖。既有数据库、标注和手工连接关系保留，手工连接在生成布局前交给 ELK。

首次生成和“重新排版”会比较 ELK 横向、纵向布局，综合考虑交叉、不同线型的重叠、折点、线长和实际长宽比；比例仍明显失衡时再尝试 ELK 折行。选择的是实际内容更合适的布局，不靠增加画布空白凑正方形。

节点仍可在文件框内拖动，连线端点跟随。增删函数、变量和调整深度时，使用当前画面作为 ELK 交互式布局的参考，沿用当前主方向，优先保留已有顺序、端口方向和视角，不再比较完整候选；单纯删除时保留剩余坐标与路径，不自动压缩空位。新增节点和连线以金色光晕呼吸提示 6 秒，在视野外时自动移入视野。

点击“重新排版”、双击单独打开函数、切换工程或打开书签时，重新计算完整 ELK 布局。增量更新仅参考当前页面，不恢复旧固定坐标存档；新增内容需要空间时，ELK 仍可能调整部分节点和文件框的位置。

文件框和目录框可拖动标题整体移动，内部节点与连线一起跟随，外层容器按需扩展，同级框不会重叠。靠近同级框的边缘或中心时显示对齐辅助线并吸附；Shift 临时关闭吸附，Esc 取消本次拖动，Ctrl+Z 撤销。单击标题仍会居中查看并切换变量范围；手动位置沿用当前页面的增量更新，不跨重新排版或重启保存。

完整布局和层级拖动松手后，会对少数绕远的跨区连线尝试其他中点连接面；只有避开节点、交叉和不同线型的重叠不增加、综合走线更简洁时才替换。不会改动手工折线或用户指定的连接面。

统一使用仓库根目录的 `启动.bat`。此前已经运行的窗口仍使用旧服务，需要关闭后重新启动；不会自动删除试用库中的数据。

正常关闭窗口或菜单“退出”会等待当前视图状态保存，再停止服务。重新打开同一工程时恢复入口函数组合、范围、分组、变量勾选、选中的函数或连线、变量面板范围与视角；各工程分别保存。显式带 `root` 的链接优先打开指定函数。此状态不包含手动拖动的布局坐标；历史回看不会覆盖最近的正常视图存档。

保存视图失败或等待超过 5 秒时，可选择重试、暂不关闭或不保存本次视图并关闭，默认保留窗口。范围下拉的默认层数作为全局界面偏好保存；恢复工程最近视图时仍优先使用该工程的范围。

自定义主题会随离线 HTML 一起恢复，PNG 底色、SVG 连线和箭头使用当前主题。弹窗打开期间暂停画布删除和撤销快捷键；TASK 建议批量应用期间切换工程会停止后续写入。

当前仍有局限：层级归属和连接关系可能使正方形候选产生更多绕线或重叠，因此不保证每张图都达到 1:1；不同样式的连线仍可能有共线段。

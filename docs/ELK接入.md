# ELK 布局

正常运行 `启动.bat` 即使用 ELK 0.12.0 排版，无需试用开关。界面与命令行导出也使用该引擎。首次安装依赖运行 `npm install`。

ELK 是唯一的自动布局引擎，负责目录、文件、函数的层级摆放与正交布线。旧布局算法、交叉优化器、固定模式和试用启动入口已移除。启动、书签跳转、调整深度、切换工程和导出均使用 ELK，不再接受旧固定坐标和手工折线覆盖。既有数据库、标注和手工连接关系保留，手工连接在生成布局前交给 ELK。

节点仍可在文件框内拖动，连线端点跟随。增删函数、变量和调整深度时，使用当前画面作为 ELK 交互式布局的参考，优先保留已有顺序、端口方向和视角；单纯删除时保留剩余坐标与路径，不自动压缩空位。新增节点和连线以金色光晕呼吸提示 6 秒，在视野外时自动移入视野。

点击“重新排版”、双击单独打开函数、切换工程或打开书签时，重新计算完整 ELK 布局。增量更新仅参考当前页面，不恢复旧固定坐标存档；新增内容需要空间时，ELK 仍可能调整部分节点和文件框的位置。

统一使用仓库根目录的 `启动.bat`。此前已经运行的窗口仍使用旧服务，需要关闭后重新启动；不会自动删除试用库中的数据。

当前仍有局限：大图不保证接近正方形，不同样式的连线可能有共线段。接入 ELK 不代表这些排版要求已经全部解决。

# 两点数据流与脉冲

在画布上按住 Ctrl，依次点击两个函数或变量（macOS 也支持 Command）：

1. 第一次点击标记第一个端点。
2. 第二次点击后按变量读写关系查找两点之间的最短路径，分别检查两个方向。
3. 以「写入函数 → 变量 → 读取函数」的实际方向播放脉冲，点击顺序不改变数据方向。

支持函数与函数、函数与变量、变量与变量。变量之间经过函数的路径表示该函数读取前者并
写入后者，因此是潜在的数据传递关系，不保证具体赋值依赖或执行先后。仅有函数调用关系
不会被当作数据流，不同结构体成员的明确读写也不会直接拼接。

查询保留当前画布、入口、标注和几何，不自动加入隐藏的中间节点。中间节点尚未显示时，
仅用临时覆盖线连接当前可见节点；信息卡的「查看路径」会列出完整中间函数和变量。
比较视图分别在 before/after 中查询，路径注明版本，禁止跨版本拼接。

按 Esc 或信息卡上的「清除」取消；第一次选择后再次点同一个节点也会取消。
已有两个端点时，下一次 Ctrl 点击开始新一轮选择。切换视图或工程会清除查询，过期响应
不会覆盖新选择。没有关系时明确提示；离线快照不重新分析源码。

路径查询限制为最多 8 条读写边，每个方向最多 12 条最短路径，并限制访问节点和扫描边数量；
命中上限或部分源码无法分析时会提示结果可能不完整。索引仍只在显式查询时按需构建并复用。

选中连线和数据流脉冲使用与线色有对比的移动光点，配有深浅双描边，避免与选中线融在一起。
脉冲不写入工程标注。PNG 保存当前画面及该帧脉冲，SVG/HTML 仍导出原图。

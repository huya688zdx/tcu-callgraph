# 两点连线追踪与脉冲

在画布上按住 Ctrl，依次点击两个函数或变量（macOS 也支持 Command）：

1. 第一次点击标记第一个端点。
2. 第二次点击后在当前画布的已有连线中查找两点之间的最短连接路径。
3. 路径上的线和节点高亮，其他节点、线和标签淡化；脉冲沿原连线箭头方向播放。

支持函数与函数、函数与变量、变量与变量。函数调用线、变量访问线、手工连线均参与追踪。
也支持 `A ← 上层 → B` 这样的共同关联，查看路径时会用实际箭头标明方向，并提示方向不连续。
比较画布中共同版本的路径显示 before/after 标签；混合版本的可见连接会注明「跨版本连线」。

查询只读取当前已显示的图，保留入口、节点、标注、连线方向和折线位置。不扫描源码、不请求
AST 变量分析、不补出隐藏的线。两点的连接需要经过尚未显示的节点时，会提示当前画布无路径，
可以先展开更多层级再查询。较远的路径会自动适配视野，也可点击「显示整条路径」再次定位。

按 Esc 或信息卡上的「清除」取消；第一次选择后再次点同一个节点也会取消。
已有两个端点时，下一次 Ctrl 点击开始新一轮选择。切换视图或工程会清除查询；增删连线或
撤销更改会重新计算当前路径，拖动只更新绘制位置。离线 HTML 也能追踪快照中已有的连线。

查找遍历当前图，不限制路径层数。最多显示 24 条最短路径，路径更多时会提示已截断，避免
分支组合过多导致页面卡顿。右键菜单里的「数据流分析」仍用于查询源码中的变量读写关系。

选中连线和数据流脉冲使用与线色有对比的移动光点，配有深浅双描边，避免与选中线融在一起。
脉冲不写入工程标注。PNG 保存当前画面及该帧脉冲，SVG/HTML 仍导出原图。

# 函数层级查找

新视图默认向上、向下各展开一层，减少首次出图的函数数量。已保存的范围偏好和工程最近视图
继续优先恢复，不覆盖用户之前选过的层数。

在画布的函数节点，或左侧文件树里的函数行上右键，选择「层级查找…」：

1. 默认「向上：查找调用者」，也可选择「向下：查找被调用函数」。
2. 输入 1–20 的整数层数。
3. 点击「查找并加入画布」。

查找始终在当前画布上追加，保留已有函数、连线、标注、状态和变量选择，不替换画布或清空
已有局部范围。例如原图有 `B → C → D` 和其他独立函数，A 调用 B 和 X：在 B 上向上找一层，
只新增 A 和 A→B，原图所有内容保留；不会新增 A 的旁支 X。没有调用者时原图保持不变。
要继续向上，可在刚找到的 A 上再找一层，也可直接在 B 上设置更多层数，沿调用链逐层查找。
多个直接调用者都会加入，不会任意挑选其中一条路径。

向下找两层只加入该函数的两层被调用函数，不反向引入这些函数的其他调用者。同一函数同一
方向再次查找时保留较深的范围；不同函数的查找结果可以累积。顶部层数和原入口保持不变，
不会把新找到的上层函数变成入口并展开其其他分支。Ctrl+Z 可返回查找前的画布。

局部查找范围随当前工程的最近视图保存，刷新、切换工程后再切回可以恢复，也可保存到书签。
源码变化后已不存在的局部查找起点会被忽略。旧书签无需重新创建，升级数据库时保留原内容。

调用层级查找不触发全工程变量分析，也不自动加入变量节点。大范围查找达到显示上限时会提示
缩小范围；普通调用图最多显示 600 个函数，每个入口的子图仍受节点额度限制。

# 函数层级查找

新视图默认向上、向下各展开一层，减少首次出图的函数数量。已保存的范围偏好和工程最近视图
继续优先恢复，不覆盖用户之前选过的层数。

在画布的函数节点，或左侧文件树里的函数行上右键，选择「层级查找…」：

1. 选择「向上：查找调用者」或「向下：查找被调用函数」。
2. 输入 1–20 的整数层数。
3. 点击「查找并加入画布」。

例如 `A → B → C → D`，在 B 上向下查找两层，会加入 C、D；向上查找一层，会加入 A。
已显示的其他函数、标注和变量选择会保留，可以对不同函数连续查找。对同一个函数的同一方向
再次查找时保留较深的范围，不会把此前找到的函数自动移出画布。局部查找独立于顶部默认层数，
不会把其他入口也统一展开到相同深度。双击函数可重新从该函数的默认范围开始查看。

局部查找范围随当前工程的最近视图保存，刷新、切换工程后再切回可以恢复，也可保存到书签。
源码变化后已不存在的局部查找起点会被忽略。旧书签无需重新创建，升级数据库时保留原内容。

调用层级查找不触发全工程变量分析，也不自动加入变量节点。大范围查找达到显示上限时会提示
缩小范围；普通调用图最多显示 600 个函数，每个入口的子图仍受节点额度限制。

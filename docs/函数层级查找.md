# 函数层级查找

新视图默认向上、向下各展开一层，减少首次出图的函数数量。已保存的范围偏好和工程最近视图
继续优先恢复，不覆盖用户之前选过的层数。

在画布的函数节点，或左侧文件树里的函数行上右键，选择「层级查找…」：

1. 默认「向上：查找调用者」，也可选择「向下：查找被调用函数」。
2. 输入 1–20 的整数层数。
3. 点击「查找」。

默认以选中的函数为唯一入口，只显示所选方向的调用链，收起原画布的其他入口、局部范围和
变量选择。例如 `A → B → C → D`，A 还调用 X：在 B 上向上找一层只显示 A、B 和 A→B，
不会显示 X、C、D；有更上层调用者时继续按设定层数查找。没有调用者时只保留 B。
向下找两层则显示 B、C、D，不会经 C 反向引入其他调用者。多个直接调用者/被调用者仍会全部
显示，查找不会任意挑选其中一条路径。顶部层数同步为本次查找范围，刷新和保存书签后也不会
把旧分支自动展开回来。标注和状态保留；Ctrl+Z 可返回查找前的入口、层数、变量选择与视角。

如果要保留原图，勾选「加入当前画布（保留已有分支）」。此模式会保留已有函数和变量选择，
将本次结果加入画布；同一函数同一方向再次查找时保留较深的范围。局部查找独立于顶部层数，
不会把其他入口统一展开到相同深度。

局部查找范围随当前工程的最近视图保存，刷新、切换工程后再切回可以恢复，也可保存到书签。
源码变化后已不存在的局部查找起点会被忽略。旧书签无需重新创建，升级数据库时保留原内容。

调用层级查找不触发全工程变量分析，也不自动加入变量节点。大范围查找达到显示上限时会提示
缩小范围；普通调用图最多显示 600 个函数，每个入口的子图仍受节点额度限制。

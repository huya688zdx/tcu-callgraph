# 头文件与宏别名

左侧文件树列出所有扫描到的 `.c` / `.h` 文件，包括没有函数实现的头文件。

例如头文件中的接口映射：

```c
#define ReadSpeed Driver_ReadSpeed
#define ReadAgain ReadSpeed
#define ReadChannel(ch) Driver_ReadChannel(ch)
```

展开头文件，勾选可调用宏，即可把它加入画布，并显示头文件分组、定义行号、调用者及实际函数。直接打开该头文件时也会优先显示其中的可调用宏。宏定义映射作为独立入口，不增加普通函数图的默认层数。

宏节点默认显示 `#define` 左侧名称。右键节点 →「显示名称」可选择左侧宏名或右侧实际函数名；单击节点后，右侧「节点详情」也提供同样的选择。切换不会改变节点标识、连线或源码，保存后刷新仍然生效，支持撤销/重做和会话导出。

名称较长时框中文字会省略，右侧详情显示完整名称。包装宏涉及多个实际函数时，名称以 `/` 分隔。右侧详情始终保留完整 `#define` 定义。图像和离线 HTML 导出保留当前显示名称。

普通函数图仍按实际函数记录调用关系，可搜索宏名或实际函数名找到头文件入口。对象式函数别名的调用也会解析，包含实参中的嵌套函数调用。

包含保护、数值常量、类型别名和只调用回调参数的宏不会作为函数加入画布。对象式宏只在展开结果对应已识别函数或调用目标时归为函数别名，避免把普通标识符常量当作函数。变量分析仍由用户按需触发。

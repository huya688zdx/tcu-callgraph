# 比较结果选择与变更颜色

比较分为解析预览和加入画布两步。点击「开始比较」后，当前工程模型、节点、标注和画面仍然保留。解析成功后弹出选择窗口，初始不勾选任何对象：

- 可以搜索名称或路径，筛选函数/变量、直接变更或全部对象，每页最多显示 100 项。
- 可以逐项勾选，也可以「勾选直接变更」。筛选和翻页保留已有选择。
- 「加入当前图」保留原图中在对照模型内仍可识别的节点，并加入选中的对象，不自动展开未选择的函数或变量。
- 原图中不能匹配到对照模型的节点会在弹窗提示；可取消并保留原画面。
- 取消、关闭或 Escape 不切换工程。退出比较恢复原工程模型、标注和原来的画面范围。
- 保留与新选的节点合计上限为 600 个。预览与当前工程绑定，切换工程后的旧预览不能继续使用。

## 颜色依据

函数和变量的「修改」只依据定义源码的实际变化；空白、注释和行号变化不算修改。仅仅受影响或作为调用上下文出现的对象保持「既存」，详情列出影响依据。定义源码相同、仅宏展开结果不同时，也保持既存并提示宏影响。定义无法完整识别时给出提示，不直接误判为修改。

连线按两侧实际调用/变量引用关系分类，不因两端节点修改、影响传播或行号变化而变色。普通工程保存的人工分类和自定义框色不会覆盖比较分类；退出比较后原标注仍在。

## 查看和调整状态

选择弹窗中的每项均可查看自动状态，也可手动改为「未修改 / 修改 / 新增 / 删除」。调整状态与勾选入图相互独立，搜索和翻页会保留调整结果。

加入画布后，函数、变量和连线的右键菜单以及右侧详情也能修改状态；鼠标悬停可查看当前状态。详情区同时显示自动识别结果，并区分自动或手动状态。选择「恢复自动判断」即可取消人工调整。比较摘要计数与颜色同步更新，修改的连线显示为黄色。

手动调整用于本次比较，刷新页面会保留；退出比较或重新解析后重新自动判断。普通工程标注独立保存。导出的图像和离线快照保留当前有效状态，离线快照中的状态只供查看。

## 文件对应

before/after 可以放在总代码目录内，但这两个目录的源码不会重复进入比较的基础工程。对照文件优先按相对路径匹配；省略了外层目录时，可以按唯一的路径后缀对应工程文件，例如 `control.c → src/control.c`，映射在预览提示中列出。同一后缀对应多个工程文件时会报错，要求保留目录层级，不猜测文件身份。

before/after 不能互相包含，也不能包含总代码目录。某个路径已进入对照范围但某侧不存在时，仍表示该侧文件被新增或删除；不在对照范围的代码沿用总代码工程。读取或分析不完整时不发布比较结果。

接口：`POST /api/compare` 返回预览，`POST /api/compare/apply` 接收预览 ID、`selectedIds` 与 `retainIds`，`POST /api/compare/cancel` 丢弃预览，`POST /api/compare/exit` 退出已应用的比较。

状态接口：`POST /api/compare/status` 携带当前 `comparisonId`、`nodeId` 或 `edgeId`、`change`。`change: null` 恢复自动判断；选择弹窗的人工调整通过 apply 请求的 `statusOverrides` 提交。
